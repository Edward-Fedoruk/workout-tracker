# Data Model: Exercise Images

**Feature**: 013-exercise-images  
**Date**: 2026-06-11

## Schema Changes

### `exercise` table — ADD COLUMN

Existing table gains one nullable column.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `image_filename` | TEXT | YES | NULL | Bare filename, e.g. `0025-EIeI8Vf.jpg`. Runtime URL: `/exercises/<image_filename>`. |

**Drizzle schema diff** (`src/db/entities/exercise/schema.ts`):

```ts
// Add to existing sqliteTable definition:
imageFilename: text('image_filename'),
```

**Migration file**: `drizzle/0003_exercise-image-filename.sql`  
Generated by `npx drizzle-kit generate`, then the 24 UPDATE statements from FR-015 are appended manually before commit.

## Static Catalog (read-only, not in DB)

**File**: `src/assets/exercise-catalog.json`

```ts
type CatalogEntry = {
  filename: string;  // e.g. "0025-EIeI8Vf.jpg"
  name: string;      // e.g. "barbell bench press"
  target: string;    // e.g. "pectorals"
  category: string;  // e.g. "chest"
};
```

Used exclusively by `ExerciseImagePicker` for client-side search. Not persisted in SQLite.

## Data Flow

```
exercises-dataset/data/exercises.json
  └── generate script → src/assets/exercise-catalog.json (committed)

public/exercises/*.jpg (committed, copied from exercises-dataset/images/)

SQLite exercise.image_filename (nullable TEXT)
  ├── set by Drizzle migration UPDATE for 24 defaults
  └── set by create/update repository methods (user picks via ExerciseImagePicker)

Runtime render:
  imageFilename → /exercises/<imageFilename> → <img src> in MUI Avatar
```
