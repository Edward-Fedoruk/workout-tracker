# Implementation Plan: Workout Routines

**Branch**: `004-workout-routines` | **Date**: 2026-05-26 | **Spec**: `specs/004-workout-routines/spec.md`
**Input**: Feature specification from `/specs/004-workout-routines/spec.md`

## Summary

Add a Routines feature that lets users create, edit, delete, and start named workout templates. Each routine holds an ordered list of exercises with suggested sets/reps. A persistent "Log | Routines" tab bar is added to the app header; the Routines tab renders a flat list of routines, each with a Start button that opens a full-page workout form pre-filled from the last logged weights for each exercise. Completed workouts are written as ordinary `workout_log` + `workout_set` rows via the existing `createWorkout` helper.

## Technical Context

**Language/Version**: TypeScript 5.5 + React 18.3 (Vite 5.4)
**Primary Dependencies**: MUI v9, Drizzle ORM 0.45, `@sqlite.org/sqlite-wasm` 3.46, material-react-table 3.2
**Storage**: SQLite-WASM via OPFS (Drizzle ORM + raw promiser for pivot queries)
**Testing**: None configured (Principle V — do not add ad-hoc)
**Target Platform**: Browser PWA (Chrome/Safari/Firefox desktop + mobile)
**Project Type**: Single-page application / PWA
**Performance Goals**: Tab switch < 1 s, routine creation (5 exercises) < 3 min
**Constraints**: Local-first, offline-capable, no backend, no React Router installed
**Scale/Scope**: Small — 2 new DB tables, ~6 new components, ~10 new DB helpers
