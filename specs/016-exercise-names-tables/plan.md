# Implementation Plan: Exercise Names in Tables

**Branch**: `016-exercise-names-tables` | **Date**: 2026-06-12 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `specs/016-exercise-names-tables/spec.md`

## Summary

Add a "Exercise Names in Tables" toggle to Settings. When on, the Workout Log table replaces exercise avatar images with text names (120 px column). The Individual Exercise page's log table always shows names unconditionally. Preference persisted in the existing `app_setting` key-value table; no schema migration required.

## Technical Context

**Language/Version**: TypeScript 5.x / React 18  
**Primary Dependencies**: Vite, MUI v6, Drizzle ORM, SQLite-WASM (OPFS)  
**Storage**: SQLite via OPFS (app_setting key-value table — existing)  
**Testing**: None configured (Principle V)  
**Target Platform**: PWA, mobile-first browsers  
**Project Type**: local-first PWA  
**Performance Goals**: Toggle effect instantaneous (local state flip + async persist)  
**Constraints**: offline-capable, no backend, single SQLite worker  
**Scale/Scope**: single-user, single-device
